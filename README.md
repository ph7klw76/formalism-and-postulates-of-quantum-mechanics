# Formalism and Postulates of Quantum Mechanics

An undergraduate learning module with a narrated lecture, original formative H5P activities and an executable Python laboratory.

The production upgrade is being prepared on a feature branch. This initial repository commit does not claim that a video or website is published.

Learning design is informed by Marshman and Singh, *Physical Review Physics Education Research* **15**, 020128 (2019), https://doi.org/10.1103/PhysRevPhysEducRes.15.020128. Original course activities will be distinguished from the validated QMFPS survey.
